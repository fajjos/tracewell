# Tracewell Frontend

React dashboard for exploring AI agent traces, prompts, responses, tool calls, latency, token usage, and detected failures.

## Responsibilities

- Provide the developer-facing Tracewell UI.
- Route between dashboard views with React Router.
- Keep API integration isolated from presentation components.
- Use TailwindCSS for a clean, fast MVP interface.

## Local Setup

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file from `.env.example`.
